# Interfaz de Neiver Labs

La aplicación Angular de la fase 1. El contexto del producto, el arranque y las pruebas están en el [README del repositorio](../README.md).

```bash
npm install
npm start
```

El servidor de desarrollo reenvía `/api` a `http://localhost:8080`. El token de acceso permanece en memoria; la renovación la gestiona la cookie del backend.
